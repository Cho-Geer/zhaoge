# Salesforce DX プロジェクト:次のステップ

Salesforce DX プロジェクトを作成した後は、次に何をすればよいでしょうか?はじめに参考になるドキュメントをいくつか紹介します。

## 変更をどのようにデプロイする予定ですか?

一連の変更をデプロイしたいのか、自己完結型のアプリケーションを作成したいのかによって異なります。[開発モデル](https://developer.salesforce.com/tools/vscode/en/user-guide/development-models)を選択してください。

## Salesforce DX プロジェクトを構成する

`sfdx-project.json` ファイルには、プロジェクトに役立つ設定情報が含まれています。このファイルの詳細については、『Salesforce DX デベロッパーガイド』の [Salesforce DX プロジェクト構成](https://developer.salesforce.com/docs/atlas.en-us.sfdx_dev.meta/sfdx_dev/sfdx_dev_ws_config.htm) を参照してください。
