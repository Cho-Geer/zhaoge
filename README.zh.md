# Salesforce DX 项目:后续步骤

您已经创建了一个 Salesforce DX 项目,接下来该做什么呢?以下是一些帮助您入门的文档资源。

## 您打算如何部署您的更改?

您希望部署一组更改,还是创建一个独立的应用程序?请选择一种[开发模型](https://developer.salesforce.com/tools/vscode/en/user-guide/development-models)。

## 配置您的 Salesforce DX 项目

`sfdx-project.json` 文件包含了项目相关的有用配置信息。有关此文件的详细信息,请参阅《Salesforce DX 开发人员指南》中的 [Salesforce DX 项目配置](https://developer.salesforce.com/docs/atlas.en-us.sfdx_dev.meta/sfdx_dev/sfdx_dev_ws_config.htm)。
